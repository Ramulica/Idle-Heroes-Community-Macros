# Cores of Origin

Summon path and hero-selection macros for Cores of Origin.

| Macro | Role |
|-------|------|
| `Select Path 1/2/3 …` | Path selection (with / without heroes) |
| `Add Mage 0 Heroes.json` · `Add Vesa 2 heroes.json` · etc. | Hero slot setup |
| `Summon Warrior 2 heroes.json` | Warrior summon flow |
| `Farm Vesa Path 2.json` | Vesa path farming |
