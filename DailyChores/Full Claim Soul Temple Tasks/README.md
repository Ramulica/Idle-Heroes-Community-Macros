# 🕯️ Full Claim Soul Temple Tasks

## What it does

Navigates to the **Soul Temple**, completes scripted **quest / task** interactions, and claims **Soul Temple rewards** (awakening milestones, session points, and related daily credit).

## About Soul Temple (game context)

The **Soul Temple** is where **Soul Awakening** happens — a major power system in modern Idle Heroes. Regular **awakenings** feed recurring events like **Soul-Awakening Gala** (milestone chests, ranking sessions, etc.). This macro does **not** replace smart awakening choices; it automates **claiming** what’s already finished.
