# All Macros — flat export folder

Every macro `.json` in this repository, collected in **one folder** for quick import or browsing.

Macros are still maintained in their category folders (`DailyChores/`, `MoveFromAToB/`, `ArenaBattles/`, etc.). This directory is a **mirror** — when you re-export or update macros, refresh this folder so it stays in sync.

**Component catalog (by category):** [All Components](../AllComponents/README.md)
